# Example investigation

Run the API and UI, then select **Open synthetic demo**. The fixture models:

```text
Seed wallet
    ├── Split wallet A ─┐
    ├── Split wallet B ─┼── Consolidation candidate ── Known-service-shaped address
    └── Split wallet C ─┘
```

All addresses and signatures in this demo are synthetic and labelled as such. Select a solid edge to
see confirmed-fixture evidence, a dashed edge to inspect the common-funder/timing formula, or the
diamond node to inspect the convergence rationale. The fixture exercises the exact analysis and UI
code used by live investigations but is never passed off as public-chain evidence.
